# 网页版开局设置 vs 新版：缺了哪些（2026-11-23）

对照对象：
- 网页版（0712 工作区，classic-fast-20261117）：`views/NewCampaign.vue`、`components/NewCampaign/GameOptions.vue`，中文文本取自 `locales/zh-cn/gameBoard/create.json`、`ultimatumsAndBoons.json`、`achievements.json`。
- 新版：`app/Scripts/Screens/PrepareScreen.cs`、`CycleScreen.cs`，开局请求见 `engine/PrototypeBackend.cs` 的 `Create`。

**关键发现**：现在用的规则核心（sourceId `5bb054d7…`，对应源码 `Arkham/Native/Session.hs` 的 `CreateRequest`），开局请求本来就能接收下面这些字段：
- `tarot`
- `undoMode`
- `asIfRuling`
- `achievementsEnabled`（默认开）
- `ultimatumsAndBoons`
- `options`（战役选项）
- `labyrinthMiniCampaign`

新版开局只发了 `campaign / scenario / seed / players / difficulty`。所以下面大部分功能**不用改核心**，补上界面并把字段带进开局请求就行。

## 已有的

| 网页版 | 新版 |
|---|---|
| 难度（简单 / 普通 / 困难 / 专家） | ✅ 准备画面右上角 |
| 剧本模式 / 支线剧情 | ✅ 选择战役页分"战役 / 旁支与挑战 / 玩家自制" |
| 重返系列 | ✅ "原版 / 重返"切换 |
| 与好友一起 / 独自控制、切换界面 | ✅ 本机轮流操作（自动切换视角）/ EOS 联机 |

## 建议顺序

1. **单场冒险模式**（#7）：核心和独立模式规则都在，只差界面；也正好接上 Yunke 刚说的"50 经验上限只在独立模式生效"。
2. **塔罗牌解牌**（#1）和 **恩赐与最后通牒**（#2）：玩家最直观的玩法变体，核心已支持。
3. **回溯模式**（#4）、**"仿佛"规则和预设**（#5）、**推荐选项**（#6）：放进准备画面的"高级规则设置"折叠区。
4. **成就**（#3）：要做一个成就页面和解锁提示，等重返系列玩得多了再做。
5. **游戏名称**（#12）：小改动，顺手做。
6. **史诗多人**（#9）、**观战**（#11）：工作量大，最后考虑。
