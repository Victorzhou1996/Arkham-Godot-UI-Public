# 交互与界面改版 · 定稿要点（2026-11-17）

本文件是开工依据，只收录**最终决定**。讨论过程、被取代的写法、核查依据见 `docs/PLAN-INTERACTION-20261117.md`（第 1–19 节）。两者冲突时以本文件为准。

**总体原则**
- 减少不必要的交互和按钮，能直接在场景上操作的就不放按钮。
- 信息以暂时性浮窗为主，少用永久弹窗。
- 卡牌不再依赖原卡图上的小字，改为插画加游戏内文字框。
- 规则核心不变：不改规则 DLL 的行为、存档格式和撤回语义。

**最终参考画面**：`docs/mock/final-table-1080p.png`（1080p 原尺寸，静态拼图）。其他样图见第 9 节。

## 0. 界面语言（Yunke 11-17 开工后追加，全项目长期沿用）

- **简约，不要华丽**：不用象牙纸铭牌、黄铜花边框、九宫格装饰框。旧的 `Ui.Button`（铭牌样式）和 `Ui.Panel`（黄铜边框）逐步替换。
- **黑色渐变背景是默认底**：文字、名字、按钮、详情都放在从屏幕边缘（或元素底部）向内渐变的黑色背景上，而不是放进带边框的盒子里。工具函数 `Ui.EdgeFade(host, color, 左, 上, 右, 下)`。
  - 名字类标签（人物名、卡名）放在**底部**的黑色渐变上。
  - 详情面板 = 屏幕一侧的黑色渐变 + 无框的文字；不画边框。
- **按钮**：`Ui.MinimalButton`——半透明黑底、无花边，悬停/强调时只有一条琥珀色细下划线。
- **卡牌**：除牌组工坊外，所有卡牌一律用重绘风格（参考版插画 + 卡名 + 游戏内文字），不显示原版卡图；需要看原卡时只在工坊或右键阅读器里。
- **画面**：整体调色参照参考版 `selection_actor`（阴影偏冷、高光偏暖、略去饱和），不要偏红。
- **背景图**：希望更"概念化"、少写实涂绘，参照参考版画风（见第 11 节试验）。
- **已落实到共享组件**（改一处、全应用生效）：`Ui.Panel` 纯暗面板；`Ui.Button` = `Ui.MinimalButton`；`Ui.Toggle`（"开/关"）；`Ui.Backdrop`（剧情/幕间的模糊压暗背景＋暗角）；`Peek`（1 秒悬停文字框，固定 440 宽，优先在卡牌上方）；`CardView` 默认重绘风格；`CardReader` 默认显示重绘卡（`printed: true` 仅工坊）。新界面一律用这些组件，不再自造边框。
- **剧情类全屏页**：模糊压暗背景、居中一栏文字、一条细分隔线、简约"继续"按钮，单击任意处继续。

## 0.1 选人画面（已实现，`app/Scripts/Screens/SelectionStage.cs`）

- 点人物或底部名字：镜头推近（约 1.4 倍）并把人物移到面板对侧；切换人物时镜头平滑移动；右键 / Esc / "返回"先拉回镜头，再按一次才离开。开场有轻微的推镜收回与淡入。"减少动效"开启时全部瞬切。
- 被选中的人物保持亮度，其余人物变为剪影、房间退暗（参考版 `selection_actor` 的做法）；叠加参考版 `selection_film` 胶片层（暗角、地面阴影、颗粒、面板一侧压暗）。
- 人物蒙版：原手绘蒙版是在缩小版画面上画的，整体错位。已用 `tools/refine_selection_mask.py` 对齐（x′≈1.27x−226，y′≈1.34y−68）并用 GrabCut 按画面精修，生成 `app/assets/bg/selection-mask-refined.png`（原蒙版保留）。点击命中改为按精修蒙版逐像素判断。

## 5. 交互

1. **拖牌打出**
   - 拖起时牌桌中央出现出牌区光圈，范围不含顶栏、左右两侧区和手牌区。
   - 松开在出牌区内：打出或使用。松开在检定框内：投入。松开在别处：回弹并轻微抖动。
   - 只有一个合法动作时直接提交，与点击走同一个 `Choose` 路径。需要目标的卡，松开后直接在场景上点目标。
   - 动效参考《杀戮尖塔》：其他手牌让位，卡牌放大、飞出、缩小淡出，数字从卡上飘出。
   - 撤回：拖回手牌区，或单击已投入的牌。
2. **就地操作**（取代行动面板）
   - 点当前地点：调查。
   - 点出口牌或房间：移动。
   - 点敌人：在旁边弹出"攻击 / 躲避"等就地菜单。
   - "选择调查员"类问题直接点头像。
   - 引擎出现未覆盖的问题类型时，退回通用选择窗口，绝不替玩家选。
3. **强制效果自动结算**
   - 只有一个需要结算时直接结算，即使旁边还有跳过、继续等不需要决定的按钮。
   - 两个及以上同时触发时，保留排序，在卡上拖动或点一次即可。
   - 可选、反应、要选目标的效果，仍交给玩家。
   - 结算时弹出提示卡条"强制 · 〈卡名〉 已结算"，约 3 秒淡出。记录里保留，撤回可用。
   - 开关沿用设置"自动略过无需选择的步骤"，默认开启。
4. **快速窗口**：手里没有可打的快速牌时自动跳过，检定前后的窗口也一样，只在记录里留一条。
5. **交互提示**
   - 底部"下一步"提示条，一句话说明现在该做什么、在哪里做。
   - 可操作的目标金色描边并轻微脉动；不可用的灰化，悬停时显示原因。
   - 需要选目标时，用箭头指向目标，其余元素压暗。
   - 前两回合显示引导气泡，设置里可关。
   - 顶栏"?"打开操作说明。
6. **检定**
   - 投入阶段：在手牌上方显示一条"技能值 对抗 难度"。
   - 揭晓：屏幕中央显示混沌标记、计算式和成败，约 2 秒后自动应用并淡出。
   - 去掉重复的"应用检定结果"按钮。
7. **浮窗与弹窗**
   - 遭遇揭示：约 2.5 秒淡出，鼠标停在上面时保持。
   - 原来单击打开的卡牌阅读器改为悬停文字框，右键仍可打开完整阅读器。
   - 记录、混沌袋：悬停按钮出预览，点击打开完整窗口。
   - 剧情幕间：点任意处继续。
   - 永久弹窗只留给剧情阅读、伤害/恐惧分配、多效果排序、结局、菜单与设置。
8. **反馈**
   - 阶段切换时，屏幕中央显示约 1.5 秒的横幅。
   - 飘字排队错开，加深色底衬，不压名字和徽章。
   - 修复撤回后飘字数字方向相反的问题。
   - 删掉行动面板底部的"已自动处理"小字。
