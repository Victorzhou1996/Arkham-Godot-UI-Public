# 第二小关《午夜假面》（01120）与战役、升级（2026-11-18）

状态用词遵守 `docs/SUPERVISION.md`：本文所有条目均为 **已做未验证**，由 Yunke 验收标记。

规则全部来自编译好的 DLL（`runtime/arkham_core.dll`）；Haskell 源码只作参考。前端只负责呈现和回答核心提出的问题。

## 1. 战役模式

- 新开局默认是**狂热之夜战役**（创建请求带 `"campaign": "01"`）。核心按顺序进行各章，自己记录战役日志、经验和创伤。
- 准备界面可选从**第一关《聚集于此》**或**第二关《午夜假面》**开始。从第二关开始时，核心会问战役设置（`PickCampaignSettings`）；该表单没有可填的项，前端发送默认值，战役日志按核心的默认情况开始。
- 章与章之间核心停在 `ContinueCampaign`：前端显示**战役界面**（章节进度 ✓/▶、每位调查员的经验与创伤、下一步是什么），按"继续"发送核心给出的下一步。
- 第一关结束后，核心按战役流程进入第二关；第二关之后进入第三关《地底噬魔》（第三关目前只有名称、森林背景和地图，没有逐地点背景和热区）。

## 2. 关卡之间的升级

- 升级由玩家发起（规则参考源码 `Native/Answer.hs`、`Native/Validation.hs`）：一章结束后的战役界面有"升级牌组（共 N 经验可用）"按钮，它向核心发送 `BeginUpgradeAnswer`；核心随后对每位调查员询问 `ChooseUpgradeDeck`。不升级就直接按"继续"。
- 当核心询问 `ChooseUpgradeDeck` 时，牌组工坊以**升级模式**覆盖在牌桌上：
  - 调查员和起始牌组来自本局（开局选的牌组，或上一次升级后的牌组；按座位存在 `setups/<游戏>-upgrade-<座位>.json`）。
  - 可用经验取自核心记录的该调查员经验（`xp`）。
  - **自动计算经验**：每加入一张卡花费其等级（至少 1）；替换同名低等级卡只花差值（至少 1）；移出卡牌不返还。超出可用经验的卡不能加入；牌组必须正好满张。
  - "完成升级（花费 N 经验）"把新牌组交给核心；"不升级，直接继续"把原牌组交给核心。
- 回答形式：`DeckListAnswer`（牌组列表 + 玩家）；核心对 `ChooseUpgradeDeck` 接受这种回答（`Native/Validation.hs` 第 59 行）。经验的实际扣除由核心按它自己的规则计算，界面上的"花费"是同一规则的预估。升级界面本身已截图确认（`evidence/upg2/`）。
- 起始牌组取自核心当前保存的牌组（存档里该调查员的 `deck`），不是开局时选的牌组文件——两者只要有一点不同，核心就会为差异收经验。
- 核心把**获得的经验（xp）**和**已花的经验（spentXp）**分开记录；界面上的"可用经验"是两者之差。
- "不升级，直接继续"发送核心的"保持牌组"形式（`UpgradeDeckAnswer`，不带牌组），不重新提交牌组。
- 程序化测试（`evidence/camprush5`，第一章快速结束后各获得 2 经验）：
  - 黛西保持牌组 → 核心记录花费 0。
  - 罗兰用"警徽（2 级）"换下一张".45 自动手枪" → 核心记录花费 2，警徽进入他的牌组；与界面预估一致。
  - 之后回到战役界面，进入第二章。
- 修复过程中发现：最初"保持牌组"是重新提交开局牌组，黛西因此被多扣了 2 经验（`evidence/camprush4`）；已改为上面的做法。

## 3. 第二关的呈现

- 场景数据：`app/assets/scenarios/01120.json`。
  - 各区背景：你的房子、河岸城、南区（历史学会 / 马妈妈的寄宿处两种）、圣玛丽医院、米斯卡塔尼克大学、商业区（第一国民银行 / 阿卡姆疗养院两种）、东城区、墓地、北区。素材来自 Yunke 提供的阿卡姆系列（`assets-source/chatgpt-20261117/g2-*`），复制为 `assets/bg/arkham-*.png`。
  - 地图总览"阿卡姆地图"（`arkham-map.png`）和各区热区。
  - 目标文字：场景卡上的官方"目标"句子；目标条另显示"胜利区异教徒 N / 6"。
- 混沌标记效果与通过概率用本关冒险卡的数值（骷髅 −X：异教徒身上最多的毁灭数；邪教徒 −2；石板 −3；困难/专家另算）。
- 敌人卡上显示毁灭标记（异教徒会积累毁灭）和线索。
- 密谋上的行动（本关是"撤退"）在右上方有单独按钮，不必去点毁灭条。
- 顶部标题、地图按钮名、准备界面的介绍和惩罚文字都随当前关卡变化。
