状态用词遵守 `docs/SUPERVISION.md`：本文所有条目均为 **已做未验证**，由 Yunke 验收标记。

做法沿用基础游戏的经验（`docs/LESSONS-BASE-GAME.md`）：规则只问核心 DLL；文字一律用 html 版官方文本；效果不确定时照 html 版；每一步截图检查。

## 1. 规则核心

- 核心 DLL 直接支持战役 `"02"`（探针 `probe/DunwichProbe.cs`：创建后各座位先问 `ChooseDeck`）。
- 五名调查员的组卡规则由核心给出（`deckBuildSchema`）：本职阶 0–5 级 + 中立 0–5 级，外加最多 5 张其他职阶 0 级；雷克斯不能带"幸运"特性的卡；各自两张专属牌 + 1 张随机基础弱点，30 张。
- 战役流程全由核心推进：序章（核心问先打 I-A 还是 I-B）、两章之后的幕间一、后面的幕间二、尾声；前端只显示和回答。

## 3. 界面

### 3.1 选择战役（新）

- 主菜单"开始新的调查" → **选择战役**（`CycleScreen.cs`）：两幅竖向画面，边缘融入黑色；写"基础游戏 · 狂热之夜"和"第一循环 · 敦威治遗产"，各自的章节名和五名调查员小卡。悬停变亮并出现琥珀色细线。
- 画面：狂热之夜用宅邸；敦威治遗产用场景卡《通往山顶的道路》（02277）的插画部分。

### 3.2 准备调查

- 战役从头连续进行（Yunke 11-18，见 `docs/CAMPAIGN-STORY-LOGIC.md`）：准备界面只显示不可点的**战役路线**（引导故事 › 第一章 … 第八章 › 尾声故事）和一句说明，不再有章节选项卡，也不显示任何一关的引言；混沌袋按难度显示（15 枚，无石板），符号标记的效果在游戏中检定时由核心给出。
- 每关的引言、结局、幕间、尾声都只在游戏里由核心按战役日志给出。

### 3.3 五人选人界面（新，`LineupStage.cs`）

- 五名调查员并排，每人一幅高竖图（各自调查员卡的插画），四边渐变到透明，没有边框。
- 平时灰暗；悬停的人变为全彩、稍微前移；点击后其他人变暗，详情从远离此人的一侧出现：名字、称号、四项技能、生命/理智、能力、引言、"选择"按钮；牌组笔记在详情下方同一侧。
- 详情面板和牌组笔记与核心盒选人共用一套代码（`SelectionStage.BuildInfo`）。

### 3.4 示例牌组

- 五人各一套示例牌组（核心 + 敦威治 0 级卡，本职阶和中立），全部经核心校验 `valid`；首次启动自动放入牌组库。

### 3.5 牌桌

- 场景背景：没有绘制的场景图，用**地点卡的插画**（未揭示时用背面插画）模糊压暗作背景；场景画面（准备界面、战役界面、剧情页）用每关第一张场景卡的插画。
- 地图：见第 3.7 节（地图是牌桌中心）。
- 混沌标记效果与通过概率：八关各自的冒险卡数值（`TableScreen.Odds.cs` `DunwichModifier`），已逐关和规则源码 `Scenario/Scenarios/<关卡>.hs` 的 `getChaosTokenValue` 核对；"再抽一个标记"按 −2 估计，"弃牌堆顶 N 张费用之和"按每张 2 估计，血色祭坛的骷髅按场上地点数估计（只用于显示）。
- html 版 locale 在迷失时空里多了一条 `elderSign`（内容是远古之物的文字），规则源码里远古印记在这一关并不变；所以不显示这一条。
- 调查员的旧印效果：佐伊 +1、雷克斯 +2、珍妮 +资源数、吉姆 +1、皮特 +2；吉姆的骷髅修正视为 0。

### 3.7 地图是牌桌的中心（Yunke 11-18 指示，两种战役都适用）

- 参考 html 版：所有地点同时摆在牌桌中央，调查员和敌人站在各自的地点上，相通的地点连线；可以拖动、缩放，让玩家始终有全局概念。不再是单独打开的"地图入口"。
- 和 html 版不同：不摆原卡图，而是**写实地图背景 + 交互小卡 + 浮窗**（`TableScreen.Board.cs`）：
  - 有绘制地图的关卡（聚集于此的宅邸剖面、午夜假面的阿卡姆地图、地底噬魔的密林）：整幅地图铺在中央，每个房间本身可以点击，能行动的房间琥珀色描边，你所在的房间绿色描边；地点小卡贴在房间左上角，不挡住房间。
  - 还没有绘制地图的关卡（敦威治八关）：按核心的 `locationLayout` 网格摆放地点小卡，背景是当前地点插画的模糊压暗图。
  - 地点小卡：插画、名字（底部黑色渐变）、隐藏值、线索、毁灭；左上角站着的调查员，右下角的敌人（可点击攻击/躲避等）和地点上的支援（如丽塔）。能行动的地点会"呼吸"发亮；你所在地点的行动按钮直接放在小卡下面。
  - 悬停小卡：浮窗显示地点卡（名称、特性、能力文字）。右键：打开卡牌阅读。
  - 小卡在缩放时保持屏幕上的大小（像地图标记），只有位置随地图移动。
- 操作：拖动空白处平移；滚轮缩放（以指针为中心）；双击放大该处、再双击回到全图；右上角"－ ＋ 全图 我的位置"；M 键看全图。左上角的地图按钮也改为"看全图"。
- 开局或换关时自动显示全图；之后保留玩家自己的视角（每次刷新不重置）。网格地图的"全图"只框住有地点的部分。
- 被取代的旧元素：屏幕中央的地点标题和出口列表（移动改为点地图上的地点）。

### 3.6 战役界面

- 章节列表、战役结局、战役日志、升级按钮都按所在战役取（`Campaigns.ForGame` 读核心的战役编号）。
- 敦威治前两章顺序可换，所以"已完成"按核心的 `completedSteps` 判断，不按顺序。

## 5. 已知未完成

- **敦威治没有写实地图**：八关的地图、场景图、结局图目前都用卡牌插画代替（地图用核心的网格排布）。要做成和基础游戏一样的写实地图，需要每关一幅地图画（像 `assets-source/chatgpt-20261117/g1-*`、`g2-*`、`g3-*` 那样），再标出各地点的位置。
- 战役第八章《迷失时空》和尾声：快速通玩在第七章失败、战役按规则结束；规则核心又不支持从中途开始，所以只能在战役里赢下第七章才能到第八章。用普通自动通玩从毁灭之地开头试了两次（`evidence/dwlwda`、`dwlwda2`）：自动通玩的打法是为基础游戏写的，在毁灭之地一直拿不到线索，赢不下来，所以**第八章和尾声的界面没有被实际走到过**（数据、官方文字、标记数值都已配好）。。幕间二也没有出现（这条路线核心没有给出幕间二的阅读）。
- 敦威治各关的特殊界面（如疯狂列车车厢向前移动、博物馆的"虚空"、无人知晓的随机地点、迷失时空的异次元地点）只经过自动通玩，没有专门检查呈现。
