# 开局经验、购买时效果、开局准备 · 相关卡牌一览（2026-11-22）

起因：Yunke 用带 **危险处境** 的黛西牌组开战役，报错"当前牌组需要3经验，超过已选预算0"。

**谁执行规则**：规则核心（0712 编译的 Haskell 规则 DLL）。它在开局载入牌组时会做这些事：
- 卡牌给的经验，日志记"危险处境 +3"；
- 购买时承受的创伤；
- 永久卡入场；
- 附属选择；
- 开局时的反应。

升级时花多少经验由 arkham.build（工坊）计算，它自带各张折扣卡的算法。

**我们这层做的事**：
- 开局经验预算检查（独立剧本规则，也用在战役开局）；
- 把核心提出的问题显示出来；
- 结转剩余经验。

状态说明：
- **已验证**：探针或界面截图实测通过；
- **已做未验证**：代码已改，但没有对应牌组可测；
- **核心执行**：规则核心负责，这次没逐张实测。
