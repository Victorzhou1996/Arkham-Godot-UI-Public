# 毁灭标记动效规范（所有关卡通用）

2026-11-20，按 Yunke 的要求定下。这套规则之后的所有关卡、所有循环都要遵守。代码在 `app/Scripts/Table/TableScreen.Doom.cs`，密谋牌子上的轨道在 `TableScreen.Plates.cs`。

## 1. 两种毁灭

| 种类 | 在哪里 | 顶上密谋轨道的显示 |
|---|---|---|
| 密谋上的毁灭 | 直接放在密谋牌上（神话阶段每轮 1 个、远古恶魔这类效果） | **红色实心点** |
| 场上卡牌上的毁灭 | 放在敌人、地点、诡计、支援等场上的卡牌上（例：抽出异教徒标记，在最近的异教徒身上放 1 个毁灭） | **淡橙色实心点**（11-20 改实心，11-21 调淡；鼠标悬停有说明："其中 N 个毁灭在场上的卡牌上，随卡牌离场而移除"） |

两种毁灭都算进密谋的推进计数（规则核心算的就是场上全部毁灭）。轨道上先画红点，再画橙圈。

卡牌上的毁灭一直显示在**那张卡上**：
- 地图上的敌人小卡：左下角毁灭角标；
- 右上概况区的敌人卡：左下角毁灭角标；
- 威胁区的卡：卡上的毁灭角标；
- 地点卡：右上角毁灭角标。

## 2. 毁灭增加

- **放在密谋上**：毁灭标记从桌面中央飞到顶上密谋轨道，落在下一个红点上，红点弹一下。
- **放在场上的卡牌上**：毁灭标记从**来源**飞到**放置的那张卡**上，在卡上停一下后融进卡上的毁灭角标；**不飞到顶上**。顶上轨道只让新出现的橙圈闪一圈橙色光晕（向外扩散、淡出）。
  - 来源：检定中抽出的标记引起的，从检定框中央起飞；其他情况从桌面中央起飞。

## 3. 毁灭减少（带毁灭的卡离场）

卡牌离场时，它身上的毁灭随之移除（2026-11-21 改：不再飞往任何地方）：
- 毁灭标记在**卡原来的位置**出现，亮一下，略微放大、上浮几个像素并淡出消散。
- 顶上轨道对应的淡橙点闪一圈光晕，然后熄灭。
- 轨道副本和牌子上的轨道一样大（13 像素的点），不出框。

## 4. 顺序

- **神话阶段**：按规则核心（`Game/Runner.hs`：放毁灭 → 检查毁灭上限 → 每位调查员抽遭遇牌），刚进入神话阶段的那一步，**先**播毁灭飞行（以及密谋推进），**再**揭示遭遇牌、出抽牌提示。
- **遭遇卡带来的毁灭**（远古恶魔等）：先揭示这张卡，再播毁灭。
- **检定中抽出的标记带来的毁灭**（异教徒标记）：先等标记翻开（约 1 秒），再播毁灭。等待期间，顶上盖着旧状态的轨道副本，落点卡上的新毁灭角标暂时隐藏，不会提前露出新数字（2026-11-21）。
- **轨道副本要在重绘后立刻盖上**，在阶段横幅播放之前：否则横幅播放时牌子上已经显示新的毁灭数，看起来像"先涨了一次"（2026-11-21）。
- **密谋被毁灭推满**：轨道闪两下红光，写"毁灭已满 · 密谋推进"，然后才翻密谋。

## 5. 新关卡接入时要检查

1. 这一关有没有把毁灭放在卡上的效果（异教徒、特殊敌人、地点、诡计）。有的话，要截图确认：卡上的角标、顶上的橙圈、飞行起点和终点。
2. 这一关有没有多个密谋（黑星升起），或者特殊的毁灭计算方式（真相幻影"其他毁灭改为减去"）。轨道上的红点和橙圈都按规则核心的计算方法来算。
3. 带毁灭的卡离场时，看毁灭标记有没有飞向卡去的地方，以及橙圈有没有熄灭。
