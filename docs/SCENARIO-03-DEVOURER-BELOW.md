# 第三小关《地底噬魔》（01142）与战役结局（2026-11-18）

状态用词遵守 `docs/SUPERVISION.md`：本文所有条目均为 **已做未验证**，由 Yunke 验收标记。

规则全部来自编译好的 DLL；前端只负责呈现和回答核心提出的问题。

## 1. 第三关的呈现

- 场景数据：`app/assets/scenarios/01142.json`。
  - 地点：主道路、四处阿卡姆密林（从六种密林里随机取四种）、仪式地（推进后出现）。核心给密林的标签是按位置的 `woods1`–`woods4`，所以背景按**卡牌编号**区分：
    - 01150（进入时意志检定）→ 荆棘；01151（离开时智力检定）→ 雾中小径；01152（用意志调查）→ 林间空地；01153（用敏捷调查）→ 悬崖；01154（用战力调查）→ 林地；01155（可治愈）→ 小屋。
  - 四处密林同名，所以按地图方位标上"西北 / 西南 / 东北 / 东南"：出口按钮、地点标题、地图上都带方位。
  - 地图"阿卡姆密林"（`forest-map.png`），主道路在下方中央（路灯处），仪式地在上方。
  - 目标文字：第一幕"全队共花费 N 线索"（来自核心）；第二幕"有调查员进入仪式地时推进"；第三幕"在本场景上放置线索，达到调查员人数的 2 倍时推进"。
- 混沌标记效果与通过概率按本关冒险卡：骷髅 −X（场上怪物敌人数）、邪教徒 −2、石板 −3、远古之物 −5；困难/专家各自的数值。远古之物标记的说明在准备界面和检定框里显示。
- 准备界面可以直接从第三关开始（战役日志用核心的默认情况）。
- 素材来自 Yunke 提供的森林系列（`assets-source/chatgpt-20261117/g3-*`）。

## 2. 战役结局

- 第三关结束后，核心把整局标记为结束；前端判断"战役的最后一章已完成"时，显示**战役结局界面**，代替单关的结果框：
  - 标题：第三关的官方结局标题（"地底噬魔 · 结局1""地底噬魔 · 未达成结局"等），下面是该结局的官方正文第一段。
  - 三章各自的结局，用官方结局标题（没打的章写"未进行"）。
  - 战役日志：核心记录的每一条（如"阿卡姆被乌默尔多斯吞噬""食尸鬼祭司仍然活着"），用中文写出。
  - 每位调查员：存活 / 已被击败 / 已发疯（战役日志的官方用语）、经验、创伤。
  - 背景用第三关对应结局的图。
- 战役日志里的"盘问过的异教徒 / 逃跑的异教徒"列出卡名（空的写"无"，被划去的标"已划去"）。
- 验证（程序化）：
  - 从第一关开局的整场战役快速测试（`evidence/fullcamp`）：第一章 → 升级（黛西保持、罗兰买 2 级卡花 2 经验）→ 第二章 → 升级 → 第三章 → 战役结局界面自动出现；三章结果、日志五条（含 6 个逃跑的异教徒）、两人的经验和创伤都正确显示。
  - 第三关自动通玩审计（`evidence/c3auto`）：出现的问题类型都有界面处理，没有报错；结束后战役结局界面自动出现。
  - 第三关牌桌、地图、目标浮窗截图：`evidence/c3look`。

## 4. 官方文本（Yunke 指示，11-18）

- 所有名称和剧情改用 html 版的官方文本：战役名"狂热之夜"（`campaignNames.json`），第三关"地底噬魔"（`scenarioNames.json`），各关介绍用官方引言（`nightOfTheZealot.*.intro`），结局用官方结局标题和正文，战役日志用官方条目。
- 场景目标条改为场景卡上的官方"目标"句子，只在后面附上线索数量。
- 混沌标记名称用官方名：骷髅、邪教徒、石板、远古之物、自动失败、远古印记。
- 卡牌文字中的 [per_investigator] 按 html 版画成图标（ArkhamIcons U+E915）。
- 记录里漏出的英文 "Revelation" 等规则词改为卡牌上的官方用语（显现、强制、目标、猎物、猎手、反击、生成）。
- 官方文本里的强调符号按 html 版处理（`helpers.ts`：`_x_` 加粗，`*x*` 斜体）。之前紧挨中文的 `_…_` 不会被识别，结局正文开头露出了下划线；已修。
- 第二关介绍用官方"引言 2"和"引言 3"两段（`introKey` 可以列多段）。官方文本里"继续 引言 3"这类阅读顺序提示不显示。介绍最多占 250 像素高，超出部分滚动，底部按钮不会被挤出屏幕。
- 记录（日志）里剩下的英文已按 html 版的做法翻译（`gameLogLocalization.ts`）：
  - `Record "…"` 显示为"记录“逃跑的异教徒：维多利亚·德佛罗”"，用战役日志官方词条加卡牌官方名；
  - "must discard down to 8 cards" 显示为"必须弃牌至剩余 8 张"；
  - `{investigator:…}` 显示为卡名。
- 我们的 `locale-zh.json` 是旧一点的副本，缺 28 个 `log.*` 词条（如 `log.attachesTo`"{card}附着于{target}"）和整组 `gameLog.*`。这些词条从 html 版原样复制到 `app/assets/data/locale-zh-extra.json`，启动时合并；`locale-zh.json` 里已有的词条优先。
- 顺带修了一个日志缺数字的问题："受到来自X的伤害点伤害和恐惧点恐惧"。原因是 `{damage}` `{horror}` 先被当成图标换成了文字，数字就填不进去了。现在先填数字。
- 检查方法：新增 QA 步骤 `scan-english:<标记>`，把屏幕上所有仍含英文单词的文字打出来。在战役存档的 15 个时间点（三章都有）打开记录各扫一遍，结果是 0 条（`evidence/p0/scanen2.log`）。主菜单上的核心版本号 "green-1.0.29" 是版本标识，保留。
