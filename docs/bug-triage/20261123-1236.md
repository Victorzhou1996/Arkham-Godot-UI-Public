## 本轮修复

### #42 不屈不挠封印标记的选项全是“选择 · 当前对象”
- **根因**：规则核心给的目标是 `ChaosTokenFaceTarget`，前端 `engine/QuestionPresenter.cs` 没有解析这种目标，就用了兜底文字。另外按钮行最多只显示 8 个按钮，15 枚可选标记只露出 7 个。
- **改法**：照 html 版 Token.vue 的做法，选项改成一排混乱标记图，图下写官方名称，每种标记一枚。最前面是核心给的“最多选择 3 项”，最后面是“结束封印标记”。用的是现有素材，没有新图。
- **改动文件**：`engine/QuestionPresenter.cs`、`app/Scripts/Table/TableScreen.Interact.cs`。
- **验证**：build exit=0。用 rules-probe 造了斯特拉的局面（测试牌组带随机基础弱点），离屏实机依次封印骷髅、封印远古印记、结束封印。袋内标记条和通过概率都跟着更新。证据在 `evidence/bugs-server/42/`。
- **没测到**：没有用鼠标真的点标记图。QA 脚本走的是和点击相同的回调。

### #41 组卡界面悬停原卡模糊
- **根因**：750×1050 的原图在 1904×984 窗口里缩到约 260×364，缩了约 2.9 倍。三线性 mipmap 在这个倍数下会混进小一级的图，规则文字就发虚了。
- **改法**：按屏幕实际像素用 Lanczos 把同一张原图缩一次，再按 1:1 采样显示（`SharpCard` / `Crisp`）。预览的大小和布局都没动。
- **改动文件**：`app/Scripts/Build/DeckEditorScreen.cs`、`DeckEditorScreen.Modes.cs`、`DeckEditorScreen.CardUpgrade.cs`。
- **验证**：build exit=0。1904x984 离屏修前修后截图对比，卡面锐度提高 44%。证据在 `evidence/bugs-server/41/compare-text-x3.png` 等。升级预览改了，但没有单独截图。
