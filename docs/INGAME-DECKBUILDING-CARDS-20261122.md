# 局内记录、冒险之间结算的卡牌：现状与方案（2026-11-22）

问题：鸦翎羽毛笔、精益求精这类卡，局内勾选或局内挣到的折扣现在要玩家自己记，到冒险之间再手动加。能不能自动带进升级？

## 先说清分工：升级时谁算经验

- **规则核心**（0712 编译的 Haskell DLL）：
  - 在冒险结局时发经验，伟大之作 +1、卡戎的银币 +2、"让上帝分辨去吧" +1、医院债务 −2 等都由它算好，直接进经验；
  - 升级时**不计价**：参考源码 `Investigator/Runner/Card.hs` 的 `handleUpgradeDeck` 只做一件事，把"已花经验"设成"全部经验"；
  - 我们实测：升级后 已得 16 / 已花 6 → 已花 16；选"保持牌组"时不变。
- **工坊（arkham.build）**：升级时花多少经验完全由它算。它内置的折扣：
  - 适应性、奥术研究、掉进兔子洞、似曾相识（需要知道上场被放逐的卡）、老练分析；
  - 定制卡的勾选格（`cus_<编号>`）；
  - 买新卡最低 1 点经验。
- **我们这层**：
  - 剩余经验结转：升级后没花完的存进结转文件，选"保持牌组"时核心自己保留，开局赠予的也接进来；
  - 已确认：无论来源，没花完的经验一直保留。

所以："arkham.build 计价"和"核心执行"的区别是：**冒险之间的升级花费只有 arkham.build 在算**，核心照单全收。凡是要靠局内发生的事情才成立的折扣或勾选，arkham.build 都不知道。这就是要玩家手记的原因。

## 方案：局内发生的事自动带进升级

1. **我们这层（牌桌）记录**：
   - 鸦翎羽毛笔、毛皮货：玩家在游戏结束 / 撤退时点了它们的反应，就记一笔（每局、每个座位一个文件），因为核心不记；
   - 绿人奖章：直接读核心的 `deckBuildingAdjustments`；
   - 精益求精：升级时读核心战役牌组里这张卡的 `customizations`，和开局元数据比较，多出来的格子算已买；
   - 似曾相识：比较上场开始时的牌组和现在的牌组，少了的就是被放逐的。
2. **升级前问一次**：鸦翎羽毛笔要玩家二选一（勾哪一格，或附属支援 −1）。在升级界面打开前弹一个小窗，选项文字用卡牌官方升级卡文本。
3. **工坊计价**（组牌会话的文件 Build/*、tools/build-engine）：
   - 升级请求带上这些记录：免费格子写进 `cus_`；放逐的卡写进 `exile_string`；
   - "下一张新卡 −1""所附支援升级 −1"作为折扣进 arkham.build 的计价；
   - 按 FAQ 1.8：买新卡最低 1 点经验，升级不受这个下限。
   - 用完的折扣清掉，没用的保留到下一次。
