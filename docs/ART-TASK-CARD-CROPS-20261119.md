# 任务：为 2090 张卡牌挑选插画裁切框

## 背景

一款卡牌游戏（《诡镇奇谈》中文版）的牌桌和组牌界面里，很多卡没有单独的插画，所以从**印刷卡面的插画区**裁一块出来用。用在两处：

- **小卡**：竖版，宽 : 高 = 112 : 157（约 0.713）。用在手牌、场上资产、敌人等小卡上。
- **横条**：横版，宽 : 高 = 4.3 : 1。用在牌组列表的一行，插画从左往右渐显。

现在的框由程序自动选（人脸检测 + 物体检测 + 显著性）。大部分还行，但不少卡没有框住画面主体：人物被切掉一半、框住了背景、亮色的杂物比人物更显眼等。请你逐张看图，给出更好的框。

## 文件

同一文件夹下：

- `manifest.json`：2090 条，每条对应一张卡：
  ```json
  {"code": "03007", "name": "保卫后方", "type": "技能",
   "image": "images/03007.jpg", "width": 600, "height": 840,
   "art":   [78, 71, 510, 386],
   "small": [188, 71, 275, 386],
   "strip": [78, 142, 510, 119]}
  ```
  - 所有框都是 `[x, y, w, h]`，单位是该图片的像素，原点在左上角。
  - `art`：插画区。裁切框必须在它里面。
  - `small`、`strip`：现在程序选的小卡框和横条框。
  - `type`：支援 783 张、敌人 598 张、事件 466 张、技能 146 张、诡计 97 张。
- `images/<code>.jpg`：印刷卡面，宽 600 像素。坐标以这张图为准。
- `previews/<code>.jpg`：缩小的预览图，上面画了三个框：青色是插画区，橙色是现在的小卡框，绿色是现在的横条框。可以先看预览，判断现在的框行不行。

## 要你做的

对每张卡判断现在的两个框好不好。不好的，给出新框。

### 小卡框（small）

- 宽 : 高 必须是 112 : 157（允许 ±1%），即 `w ≈ h × 0.7134`。
- 必须完全在 `art` 里面：`x ≥ art.x`，`y ≥ art.y`，`x + w ≤ art.x + art.w`，`y + h ≤ art.y + art.h`。
- 可以比现在的框小（放大主体），但 `h` 不要小于 `art.h` 的 55%，否则太糊。
- 框住画面的**主体**：
  - 有人物或怪物时，脸和上半身优先，头顶不要贴边或被切掉。
  - 有手持物品时（武器、书、护符等），物品和手要在框里。
  - 卡名说的东西优先。例如卡名是“刀子”，就框住刀；卡名是一个人物，就框住这个人。`name` 字段是卡名。
  - 没有明显主体的风景或抽象画面，框住最有看点、最亮或细节最多的部分。
- 不要框进卡面的边框、文字、图标（插画区边缘可能带一点卡框装饰）。

### 横条框（strip）

- 宽 : 高 必须是 4.3 : 1（允许 ±2%）。
- 必须完全在 `art` 里面。
- 宽度可以小于 `art.w`，但不要小于 `art.w` 的 70%。
- 横条的左侧 40% 会被渐变遮住，只有**右侧 60%** 清楚可见，所以主体（脸、物品）放在框的右半边。

## 输出格式

一个 JSON 文件 `crops.json`。只写需要改的卡，没写的卡保留现在的框：

```json
{
  "03007": {"small": [180, 90, 240, 336], "strip": null},
  "09021": {"small": [120, 100, 250, 350], "strip": [150, 160, 430, 100]},
  "07076": {"small": null, "strip": [100, 520, 470, 109]}
}
```

- 键是 `code`。
- `small` 和 `strip` 各自是 `[x, y, w, h]`（整数像素，按 `images/` 里那张图的坐标），或 `null` 表示这一项保留现在的框。
- 每条可以另加一个 `"note"` 字段，用一句话说明为什么改，可选。

## 分批

图很多，可以分批做。按 `manifest.json` 的顺序，每批 100～200 张，每批输出 `crops-<批号>.json`（例如 `crops-01.json` 覆盖第 1～150 条）。格式同上，我这边会合并。

## 自查

交付前请检查每个给出的框：

1. 宽高比在允许范围内。
2. 完全在 `art` 里面。
3. 小卡框的 `h ≥ 0.55 × art.h`；横条框的 `w ≥ 0.7 × art.w`。
4. 主体完整：没有切掉头、脸，或卡名所指的物品。

不满足的框我这边会丢弃，保留现在的框。
