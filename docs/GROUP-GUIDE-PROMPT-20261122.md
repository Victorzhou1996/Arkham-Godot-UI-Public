# 入群引导图（新 UI 版）· 2026-11-22

用途：群文件和入群时发的引导图。主推换成新 UI 版；Windows 老客户端改为备用版本。风格沿用 `inbox` 里旧引导图（深绿顶栏 + 月亮城镇 + 米色正文 + 金色分隔线），让群友一眼认出是同一套。

## 制作方式

- **文字不要让文生图直接画**：中文字容易错字、缺字。推荐：AI 只出背景和插画，文字和版式用 html 排版后截图（字体和官方译名按项目规则）。
- **顶栏插画**：直接用旧引导图右上角的月亮和城镇剪影（原图裁切），不要重画。
- 尺寸：竖版，宽 1080，高按内容定（旧图约 1080×1460），PNG，文字清晰放大不糊。

## 文案（逐字使用，不要改动）

**顶栏**
- 小标签：调查员指南
- 大标题：诡镇奇谈怎么玩？
- 副标题：新 UI 版上线，电脑和手机都能玩，还能跨设备联机。

**01 新 UI 版（主推，醒目）**
- 标题：新 UI 版（推荐）
- 徽标：群文件下载
- 两行：
  - Windows 版（EXE）：从群文件下载，安装后即可游玩。
  - 安卓版（APK）：从群文件下载，安装后即可游玩。
- 高亮条（用绿色底或金色框突出）：**支持跨设备联机：电脑和手机可以一起玩。**

**02 备用版本**
- 标题：Windows 老客户端（备用）
- 一句：更新主要集中在新 UI 版；老版本保留在群文件，需要时再用。

**03 其他方式（字号小一档）**
- 标题：网页版与自建服务器
- 群主服务器网页版：国内 https://<DOMESTIC_SERVER_IP>/　海外 https://<OVERSEAS_SERVER_HOST>/
- 自建服务器 Linux 版：从群文件下载 .tar.gz 部署包，在自己的 Linux 服务器上开服。

**页脚**
- 版本状态截至 2026 年 11 月 22 日

## 版式

- 顶部深绿色横幅（约占高度 20%），左上小标签，右上月亮城镇插画，大标题白色衬线体。
- 正文米色底，每个区块之间用金色细线分隔，左侧用斜体数字 01、02、03 编号。
- 01 区块最大、最醒目；02 次之；03 最小，颜色更淡。
- 下载徽标用浅绿底小圆角标签；"跨设备联机"高亮条放在 01 区块末尾。
- 图标：电脑（Windows）、平板/矩形屏（安卓）、层叠方块（新 UI）、服务器（自建）。

## 不要

- 不要出现“群主版：开发中”或任何未开放的内容。
- 不要写具体的文件名、版本号或下载次数，除非你另外提供。
- 不要把老 Windows 客户端放在主推位置。
- 不要用非官方译名。
