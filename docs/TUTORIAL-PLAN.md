# 新手教程 · 思路稿

Yunke 的要求：固定卡组的双人局，玩基础游戏第一关，存档可以保留。

## 1. 整体做法

- **关卡**：狂热之夜 第一章「聚集于此」，从书房开始，到食尸鬼祭司或撤离为止。
- **两名调查员**：
  - 罗兰·班克斯（守卫者）：负责战斗。
  - 黛西·沃克（探求者）：负责调查。
  - 两人分工最明显，正好分别教"打怪"和"拿线索"。
- **卡组**：用两人的固定卡组（核心盒推荐卡组，游戏里已有示例卡组 `example-01001` / `example-01002`）。
- **怎么引导**：前两轮用"固定开局"，牌序和关键检定都事先安排好，按剧本一步步讲；之后转为"第一次遇到时"的动态提示。见 §4。
- **提示长什么样**：
  - 一个文字框，加上被讲到的地方的呼吸边框高亮。高亮按蒙版原则：盖满主体，四周渐变，不加硬边。
  - 文字框里有"知道了"和"跳过教程"两个按钮。
  - 文字全部中文，规则术语用官方译名。
- **存档**：
  - 教程局就是一局普通存档，名字标"新手教程"，出现在"继续调查"里。
  - 打完可以按普通战役接着玩第二章「午夜假面」。
- **入口**：
  - 主菜单加一项"新手教程"。
  - 第一次启动游戏时问一句"要先玩一下新手教程吗？"。
- **记录**：哪些提示看过存在用户数据里；设置里加"重新显示教程提示"。

## 2. 需要引导的内容（按大致出现的顺序）

### A. 开局前
1. 调查员卡：
   - 意志、智力、战斗、敏捷四项属性；生命值和理智值。
   - 罗兰和黛西各自的能力。
2. 牌组和手牌：起手 5 张；起手调度（可以换掉不想要的牌，一次）。
3. 资源：开局 5 个，用来打出卡牌。
4. 弱点卡是什么（如果卡组里带弱点，见 §3 第 2 个问题）。

### B. 桌面认识（我们自己的界面）
5. 地图上的地点：
   - 划过看信息，点开看原卡。
   - 发光的是可以操作的。
6. 场景卡和密谋卡在哪；毁灭标记、线索标记在哪。
7. 悬停看卡（文字模式 / 原图模式），点开看原卡。
8. 日志在哪里看，以及"结束回合"按钮。

### C. 调查阶段 · 行动
9. 每回合 3 个行动，以及行动有哪些：调查、移动、抽牌、拿资源、打出卡牌、启动能力、战斗、闪避、交涉。
10. 两人轮流：先手玩家先做；一名调查员做完 3 个行动后，轮到另一名。
11. **切换视角**（Yunke 11-23：玩家操作两个，"因为还要教切换视角"）：
    - 轮到哪名调查员做选择，桌面会自动切到他的视角（"切换调查员…"）。
    - 点队友的头像可以随时切过去，看他的手牌、交战的敌人和威胁区。头像上标着"当前视角"或"等待操作，点击切换"。
    - 切过去只是看；没轮到他的时候，不能替他行动。
    - 遭遇牌、技能检定这类问到另一名调查员的事，要先切到他那边再选。

### D. 技能检定与混沌袋
12. 检定怎么算：属性值 + 投入卡牌的图标，对比难度；抽一个混沌标记修正。
13. 投入卡牌：
    - 手里的牌可以只拿来加图标。
    - 同一地点的队友也可以投入。
14. 特殊标记：骷髅、邪教徒、石板、远古邪物（看场景卡背面）；触手是自动失败，旧印是好标记。

### E. 地点与线索
15. 遮蔽值就是调查的难度；成功就拿一个线索。
16. 地点之间怎么连通；书房一开始出不去，要推进场景才能离开。

### F. 场景与密谋
17. 场景：花费线索推进，比如第一幕"被困于此"。
18. 密谋：每轮神话阶段加毁灭，毁灭够了就推进，比如"到底发生了什么？！"。教会玩家"时间是有限的"。

### G. 神话阶段与遭遇牌
19. 每轮开始先放毁灭，再每人抽一张遭遇牌。
20. 诡计牌：比如攫噬之手、腐烂的尸体。
21. 敌人生成：比如鼠群、食尸鬼爪牙。

### H. 敌人
22. 交战：敌人进入你的地点并与你交战。
23. 战斗和闪避：用哪项属性、成功之后会怎样。
24. 借机攻击：交战中做战斗、闪避以外的行动，会被攻击。
25. 敌人阶段：猎手敌人会移动，交战的敌人会攻击。
26. 精英敌人：食尸鬼祭司。

### I. 伤害、恐惧与被击败
27. 伤害和恐惧可以分给资产（比如盟友）承受。
28. 生命或理智降到 0 就被击败：本关出局，并得到创伤。

### J. 维持阶段
29. 重置卡牌、每人抽 1 张牌、拿 1 个资源；手牌超过 8 张要弃掉。

### K. 结局与战役
30. 决议（结局）有几种，比如房子烧不烧、丽塔·钱德勒去向。
31. 经验值和创伤，战役日志记了什么。
32. 两章之间怎么升级卡组，以及第二章怎么接着玩。

## 4. 固定开局与动态触发

### 4.0 抽牌顺序能不能固定

默认是随机的：牌库、遭遇牌堆、混沌袋都由规则核心洗牌和抽取。但规则核心自带几种有限的"调试操作"，和其他操作一样经过规则核心、记进对局历史、可以撤回。教程可以用它们把开局固定下来：

| 核心操作 | 教程里用来做什么 |
|---|---|
| `moveCard` → 某人手牌 / 牌库顶 / 牌库底 / 遭遇牌堆顶 | 固定起手、固定接下来抽到的牌、固定遭遇牌的顺序 |
| `setForcedDraws`（指定本次检定抽出的混沌标记） | 第一次调查必定成功；安排一次失败、一次特殊标记，讲清楚检定 |
| `selectDraw` / `selectEncounterDraw` | 备用：直接指定下一张抽哪张 |

这些操作只在"新手教程"这一局里用，普通对局不碰。

### 4.1 卡组与弱点（Yunke 11-23 已定）

- **罗兰·班克斯**：核心盒推荐卡组；固定基础弱点是**黑帮打手**（敌人，猎手，只对承受者；也可以花 4 资源"谈判"弃掉它）。正好讲清交战、战斗、闪避，以及"不一定非打不可"。
- **黛西·沃克**：核心盒推荐卡组；固定基础弱点建议用**恶灵附身**（放进威胁区，每项技能 −1；花两个行动可以弃掉它）。讲威胁区，以及"用行动启动卡牌上的能力"。
- **专属弱点**：两人还各有一张专属弱点（罗兰的掩盖罪证、黛西的死灵之书），这是牌组必带的。教程里先放到牌库底，不让它们出现，免得一局里弱点太多；只在讲弱点时提一句。

### 4.2 固定开局（前两轮）

| 时机 | 安排 | 讲什么（§2 编号） |
|---|---|---|
| 开局 | 两人起手固定：罗兰拿到 .38 特制手枪和带战斗图标的卡，黛西拿到黛西的手提包、一张书籍资产和带智力图标的卡 | 1–4 调查员卡、起手调度、资源 |
| 第 1 轮 · 黛西 | 第一次调查书房，强制抽到一个好的混沌标记 → 成功拿到线索 | 9、12–15 行动、检定、线索 |
| 第 1 轮 · 黛西 | 第二次调查，强制抽到触手 → 失败 | 14 特殊标记、失败 |
| 第 1 轮 · 罗兰 | 自动切到罗兰；打出 .38 特制手枪 | 10–11 轮流、切换视角；打出资产 |
| 第 1 轮 · 维持 | 罗兰抽到**黑帮打手**（放在他牌库顶） | 29 维持阶段；弱点出现 |
| 第 2 轮 · 神话 | 毁灭 +1；遭遇牌堆顶固定：罗兰抽到攫噬之手（诡计，敏捷检定），黛西抽到鼠群（敌人） | 18–21 密谋推进、神话阶段、遭遇牌、诡计、敌人生成 |
| 第 2 轮 · 罗兰 | 黑帮打手和罗兰交战；用手枪攻击（强制成功），或者谈判 | 22–24 交战、战斗、借机攻击 |
| 第 2 轮 · 黛西 | 黛西攒够书房的线索，两人推进场景"被困于此" | 17 场景、推进；16 地点连通 |

推进第一幕以后，固定开局结束，之后完全按正常规则随机进行，只保留动态提示。

### 4.3 动态触发节点

玩家不一定照剧本走（比如让罗兰去调查），所以每个提示都按"条件触发"写，固定开局只是让这些条件尽早、按顺序出现。每次规则核心给出新局面时检查一遍：

| 类别 | 触发条件（从规则核心的局面和问题里读） | 例子 |
|---|---|---|
| 规则核心问的问题 | 问题的类型和选项 | 第一次出现行动菜单 → 讲 3 个行动；第一次出现投入卡牌 → 讲投入；起手调度 → 讲换牌 |
| 检定结果 | 揭示的混沌标记 | 第一次揭示骷髅、邪教徒、石板、远古邪物、触手、旧印，各讲一次 |
| 局面变化 | 前后两个局面的差异 | 新敌人入场、和你交战、受到伤害或恐惧、毁灭增加、密谋或场景推进、新地点揭示、拿到线索、抽到弱点 |
| 阶段 | 当前阶段 | 第一次进入神话阶段、敌人阶段、维持阶段 |
| 视角 | 被问到的调查员不是当前视角 | 第一次自动切换视角时讲切换（§2 第 11 条） |

**规则**：
- 每条提示只出现一次，看过的记下来。
- 同时满足多条时排队，一次只显示一条。
- 提示只解释，不替玩家点；"跳过教程"之后只剩普通游戏。
- 提示文字放在单独的表里（条件 → 高亮哪里 → 中文说明），方便以后改。

### 4.4 需要实测确认的

- 固定起手要在起手调度之前完成（用 `moveCard` 换手牌）；具体时机要在规则核心上实测。
- `setForcedDraws` 需要当前检定的编号，要在检定开始、揭示之前调用；同样要实测。
- 每张卡在核心里的编号（cardId）是开局后才有的，所以固定开局是"开局后按卡名找到那张卡再移动"，不能事先写死。

## 5. 实施记录（2026-11-23，第一版，待 Yunke 手动试玩）

### 入口与流程（Yunke 11-23：从选剧本和选人开始，线性、固定）
1. 第一次在主菜单点"开始新的调查"时，弹窗问"要先玩一下新手教程吗？"。主菜单另有常驻的"新手教程"。
2. **选择战役**：除「狂热之夜」外都变暗，点了也只提示；提示框指向狂热之夜。
3. **准备调查**：难度固定"简单"（其他难度按钮变灰）；隐藏"EOS 联机主持"和"牌组工坊"。提示依次讲：战役路线、难度和混沌袋 → 点"＋ 选择调查员" → 再选黛西 → 牌组和弱点 → 点"开始调查"。座位上的牌组下拉框锁定、"移出"隐藏，最多两个座位。
4. **调查员群像**：第一次只能点罗兰·班克斯，第二次只能点黛西·沃克；点别人会提示"新手教程这一步请选择…"。牌组自动用教程牌组。
5. **牌桌**：两人各 33 张（15 种各 2 张 + 专属 2 张 + 固定弱点 1 张）。到第一个正式的行动窗口时，按 §4 换成固定起手、排好牌库顺序和遭遇牌；之后按条件出现提示（共 29 条）。
6. 提示框上有"退出教程 / 跳过教程"，退出后就是普通游戏。

### 和 §4 不同的地方
- **混沌标记不固定**：规则核心只在"稳定的行动窗口"接受移动卡牌；而技能检定的投入阶段两名调查员都能投入，属于"同时提问"，核心拒绝检定类调试操作（`Finish active costs or simultaneous questions before test debug`）。改为让结果保持随机，提示按实际抽到的标记解释（成功、失败、各种特殊标记第一次出现时）。
- **固定起手的时机**：核心在起手调度时不允许移动卡牌，所以起手调度照常进行（提示里说"直接确认"），到第一个行动窗口再换成固定起手。

- 提示：欢迎、领队、起手调度、调查员、行动、打出资产、线索、混沌标记、场景推进条件、结束回合、调查书房、视角切换，都按条件出现；高亮落在对应位置。
