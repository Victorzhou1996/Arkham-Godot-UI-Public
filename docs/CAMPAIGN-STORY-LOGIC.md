# 战役剧情逻辑：规则核心怎么推进（狂热之夜 · 敦威治遗产）（2026-11-18）

Yunke 11-18 指出：基础版三关、一循环八关都是**连续**的战役，不是可以分开选的关卡；每关的引言和结局随前面的流程和结局而变，所以界面上不该有"每关一份固定引言"。本文件是读 html 版前端和规则源码（只作参考，不作后端）之后的总结，界面改动以此为准。

状态：已做未验证。

## 1. html 版怎么做

- **新游戏默认是完整战役**（`NewCampaign.vue`，`fullCampaign = 'FullCampaign'`）：只选战役、难度、牌组，开始时不传章节（`newGame(…, campaignId, null, …)`），由核心从**引导故事 / 序章**开始。
- "从某一章开始"是另一个模式（`PartialCampaign`），要先填战役日志设置表；"单独剧本"（`Standalone`）也是另一个模式。这两者都不是正常战役流程。我们这一版规则核心对敦威治的中途开始回答"尚未实现"。
- 所有剧情文字（序章、每关引言、结局、幕间、尾声）**只**来自核心的 `Read` 问题：核心发来的是 locale 键（`I18nEntry`），html 照键取官方中文显示（`StoryEntry.vue` / `FormattedEntry.vue`）。前端自己不挑引言版本。
- 核心在剧情和设置单里用 `validate` 标出"本次适用 / 不适用"的段落（`ModifyEntry` + `ValidEntry` / `InvalidEntry`）。html 把**不适用的段落显示为灰色**（`.invalid { color: #666 }`），适用的正常显示。

## 2. 规则核心的战役流程

一局战役 = 一串战役步骤（`CampaignStep`）。每一步结束后核心停在"继续战役"（`ContinueCampaign`），带着下一步；章节之间插入"整理牌组"（`UpgradeDeckStep`）。

### 2.1 狂热之夜（`Campaign/Campaigns/NightOfTheZealot.hs`）

```
序章（storyI "prologue"）→ 聚集于此 01104 → 午夜假面 01120 → 地底噬魔 01142 → 战役结束（没有尾声）
```

每关内部：`PreScenarioSetup`（引言）→ `Setup`（设置单，按日志 validate）→ 游戏 → `ScenarioResolution`（结局文字 + 经验 + 写日志）→ 下一步。

| 关卡 | 引言（核心按日志选） | 设置受日志影响 | 结局写入日志 |
|---|---|---|---|
| 聚集于此 | 只有 `intro`（标题 + 正文） | — | 无结局：房子仍在、食尸鬼祭司仍活着，可让主导调查员加入丽塔；结局 1：房子烧毁，丽塔，主导调查员 1 精神创伤；结局 2：房子仍在，主导 +1 经验；结局 3：丽塔被迫找别人帮忙、房子仍在、祭司仍活着，剩下的调查员被杀 |
| 午夜假面 | `intro`（说明"按日志读引言 1 或 2"）→ **引言 1**（日志有"丽塔被迫找别人帮忙"）或 **引言 2**（否则）→ **引言 3** | 房子烧毁：从河岸区开始、"你的房子"不在场；否则从你的房子开始。祭司还活着：洗入遭遇牌堆。侍僧数量按人数 | 结局 1 / 2（无结局按结局 1）：审问过的异教徒、逃走的异教徒（未击败的 + 异教徒牌堆剩余 + 第一张密谋时的蒙面猎手）；结局 2 记"已过午夜"；击败祭司则划掉"祭司仍活着" |
| 地底噬魔 | 只有 `intro` | 逃走的异教徒人数 → 密谋上的毁灭（(人数+1)/2）、设置说明；已过午夜 → 每人随机弃 2 张；祭司仍活着 → 洗入；加 1 个远古邪物标记；4 个随机密林地点 | 无结局：阿卡姆屈服；结局 1 仪式被打断（+5 经验）；结局 2 击退乌莫达斯（+10）；结局 3 献祭了丽塔 |

### 2.2 敦威治遗产（`Campaign/Campaigns/TheDunwichLegacy.hs`）

```
引导故事（选：先打 I-A 课外活动 还是 I-B 百赌百胜）
→ 另一章 → 幕间 I：阿米蒂奇的命运
→ 博物馆之夜 → 疯狂列车 → 血色祭坛
→ （血色祭坛有结局时）幕间 II：幸存者   （无结局时跳过）
→ 无人知晓 → 毁灭之地 → 迷失时空 → 尾声
```

- 幕间 I：日志有"调查员昏迷了数小时"→ 阿米蒂奇的命运 1（阿米蒂奇被绑架，全员 +2 经验）；否则 → 命运 2（救出阿米蒂奇，可加入牌组）。
- 幕间 II：逐个检查谁**没有**被献祭给犹格·索托斯，各读一段、记"幸存"、可加入牌组。
- 尾声：日志有"你警告了镇民"→ 尾声 2，否则尾声 1；然后战役结束。
- 每关引言的分支（`Scenario/Scenarios/*.hs` 的 `PreScenarioSetup`）：
  - 博物馆之夜：阿米蒂奇被绑架 → 第 1 部分，否则第 2 部分；
  - 无人知晓：玩家选"安抚"或"警告"镇民 → 第 1 或第 2 部分（选择本身写进日志，影响尾声）；
  - 毁灭之地：娜奥米替你们撑腰 → 读第 1 部分，否则跳过；
  - 课外活动、百赌百胜、疯狂列车、血色祭坛、迷失时空：只有一段引言（但设置单仍随日志变）。

## 3. 前端应当怎么做（由此得出的规则）

1. **战役只能从头开始**，按核心给的顺序一章接一章；准备界面不再有章节选项卡，只显示整条路线（不可点），写明"从引导故事/第一章开始，依次进行"。
2. **准备界面不显示任何一关的引言**。引言、结局、幕间、尾声只在游戏里、由核心的阅读页给出。
3. 阅读页（和设置单）里核心标为"不适用"的段落，照 html 版**显示为灰色**，不能和适用的段落一样显示。
4. 牌桌上悬停目标看到的"场景"文字：用**这一局核心实际读过的引言**（游戏中记录下来），而不是每关写死的一份。
5. 场景画面（剧情页、准备、结局背景）如果依赖流程（午夜假面：房子烧了就没有"你的房子"），按核心的战役日志选。
6. 结局文字一律按核心记下的结局编号取官方文字（已经如此）。

## 4. 改动（已做未验证）

- 准备界面：去掉章节选项卡和"本关引言"，改为不可点的**战役路线**（序章 › 第一章 › … › 尾声）和一句说明；"开始调查"永远从战役开头（`Create(…, campaign, null)`）。去掉按章节显示的符号标记效果（每章不同，检定时由核心给出）。`CampaignDef.LateStart` 删除，换成 `PrologueName / EpilogueName / RouteNote`。
- 剧情页：核心标为不适用的段落（`InvalidEntry`）显示为灰色（`ClientLocale.Flavor` 加 `<dim>`，`CardReader` 渲染）。很长的剧情页（结局 + 日志条目）在框内滚动，"继续"按钮始终在屏幕内。
- 牌桌目标浮窗的"场景"文字：改为本局核心实际读过的引言（`TableScreen.Story.cs`，按局保存在 `setups/<局>-story.json`），去掉重复标题和"继续 引言 3"一类的阅读指引。各关 `introKey` 全部删除。
- 场景画面按战役日志选：午夜假面在"房屋被烧毁"时用河岸城（`exteriorByRecord`）。

## 5. 狂热之夜按顺序通玩（`evidence/pz3`，日志 `evidence/p0/pz3.log`）

两人（罗兰 + 黛西），简单。核心读出的剧情键（`AUDIT_STORY`），顺序与第 2.1 节一致：

```
序章 → 聚集于此 引言 → 聚集于此 无结局（房屋还在、祭司还活着）
→ 午夜假面 引言（说明）→ 引言 2（丽塔没有被迫离开，所以不是引言 1）→ 引言 3 → 午夜假面 无结局 → 结局 1
→ 地底噬魔 引言 → 地底噬魔 无结局 → 战役结束
```

- 午夜假面从"你的房子"开始（房屋还在），场景画面也是你的房子。
- 地底噬魔开局密谋上有 3 点毁灭：6 名逃跑的异教徒，(6+1)÷2 = 3，与核心规则一致。
- 战役结束画面：三章结果（未达成 / 结局 1 / 未达成）、战役日志（祭司还活着、房屋还在、阿卡姆被吞噬、盘问过的异教徒：无、逃跑的六人）、两人的经验和创伤。
- 未走到的分支：房屋被烧毁（需要聚集于此结局 1）、丽塔被迫离开（结局 3）。这两条的引言和起点由核心按日志决定，界面只多了"河岸城"画面这一处判断。

## 6. 敦威治遗产按顺序通玩（`evidence/pd4`，日志 `evidence/p0/pd4.log`）

两人（佐伊 + 吉姆），简单，从准备界面开始（准备界面只显示路线，不能选章）。到目前为止核心读出的顺序：

```
引导故事（选择：先打 I-A 课外活动 / 先打 I-B 百赌百胜）→ 选了 I-A
→ 课外活动 引言 → 课外活动 未达成结局（记"沃伦·莱斯教授被绑架""未能成功拯救学生"，加石板标记）
   结局页写"如果这是第一场冒险，进入 I-B，否则进入幕间 I"——核心随后进入了 百赌百胜
→ 百赌百胜 引言 → 百赌百胜 结局
→ 幕间故事 I：说明页（"调查员昏迷了数小时 → 命运 1"一行灰色，不适用；"否则 → 命运 2"正常）→ 阿米蒂奇的命运 2
→ 博物馆之夜 引言（"阿米蒂奇被绑架 → 第一部分"灰色；"救出了阿米蒂奇"正常）→ 第二部分 → "混沌"区域说明
```

→ 博物馆之夜 未达成结局（记"调查员未取得死灵之书"）
→ 疯狂列车 引言 → 列车移动说明 → 被击败的结算 → 结局 2（记"调查员前往敦威治时迟到了"；持有阿米蒂奇的调查员被击败，核心记"阿米蒂奇被绑架"）
→ 血色祭坛 引言 → "隐藏密室"说明 → 未达成任何结局（记"仪式已完成"、犹格·索托斯的祭品）
→ （血色祭坛无结局，核心按规则**跳过幕间故事 II**）
→ 无人知晓 引言（选择：安抚村民 / 疏散村民）→ 选了安抚 → 第 1 部分（记"你们安抚了村民"）→ 未达成任何结局
→ 毁灭之地 引言（"得到娜奥米的支持 → 第 1 部分"灰色，因为百赌百胜没有记下这一条，核心跳过第 1 部分）→ 未达成任何结局（官方文字转到结局 2：两人发疯，战役失败）
→ 战役结束（第八章 迷失时空 标为"未进行"）
```

和第 2.2 节核心逻辑一致：两章顺序由引导故事的选择决定、两章都打完才进幕间 I、幕间 I 和博物馆的引言都按日志里的阿米蒂奇状态取分支，不适用的分支照 html 版显示为灰色。

本轮顺带修的显示问题：
- 引导故事的两个选项按钮显示了官方文字里的强调符号（"推进至 _冒险 I–A: 课外活动_"）→ 按钮去掉 `_`/`*`。
- 课外活动结局里"加入1个{'{'}tablet{'}'}混乱标记"→ 按 vue-i18n 规则还原成 {tablet}，再显示为"石板"。
- 新的路线行在敦威治（十步）时界面卡死（换行容器没有固定宽度导致布局死循环）→ 改为每行最多五步的固定行。
- 无人知晓的两个选项是整句话，并排时比页面宽，整页文字被推到屏幕右侧 → 长选项改为上下排列。
- 战役结束画面：疯狂列车一栏的结果是空的（核心记为"无结局"，这一章官方没有"无结局"标题）→ 没有官方标题时写"未达成结局"/"结局 N"；战役日志很长，把调查员和按钮挤出屏幕 → 日志分两栏、在框内滚动，调查员小卡缩小；日志里被划掉的条目（`crossedOut`）标"（已划去）"。
- 日志里同时有"阿米蒂奇被绑架"和"调查员解救了阿米蒂奇"：查过规则源码，是先在幕间 I 被救出、又在疯狂列车里因持有者被击败而被绑架，两条都是核心真实记录的，按记录顺序显示，不是错误。

没有走到的部分：第八章 迷失时空、尾声故事、幕间故事 II。毁灭之地失败时战役按规则结束，要看到第八章必须赢下毁灭之地；自动通玩打不赢这一章。这几步的剧情同样只由核心发出（尾声按"你们警告了镇民"取尾声 1 或 2），界面不需要另做判断。
