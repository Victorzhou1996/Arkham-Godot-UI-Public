# 手机版触屏逻辑（2026-11-22）

状态：已写好并编译通过，**还没在真机上验证**。代码在 `G:\AHMobile-20261122\overlay\app\Scripts\Mobile\TouchInput.cs`，只放进手机版镜像，游戏目录里的代码一行没改。

## 1. 做法

游戏按"鼠标 + 键盘"写成：悬停看信息、右键看原卡、滚轮缩放地图、键盘快捷键。没有任何一处处理触摸事件（盘点结果见第 4 节）。

手机版不逐个改界面，而是加一层"触屏翻译"：关掉 Godot 自带的"触摸当鼠标"，由这一层把手指动作翻译成游戏已经认识的鼠标和键盘事件。好处：

- 桌面版和手机版用的是同一套界面代码，以后主程序改界面，手机版自动跟上；
- 规则核心、存档、联机这些都不受影响。

## 2. 手势对照表

| 手指动作 | 相当于 | 游戏里的效果 |
|---|---|---|
| 轻点 | 左键单击 | 选择、出牌、点按钮。点完后"虚拟鼠标"立即离开，不会留下悬停框 |
| 快速点两下 | 两次普通单击 | 11-22 按 Yunke 要求去掉了双击（"双击的逻辑去掉吧"），不会再合成成双击 |
| **按住 0.4 秒** | 鼠标悬停 | 信息框立刻出现（敌人战斗/生命/伤害、使用次数、地点线索/隐蔽值、密谋毁灭标记、混沌标记效果等），手牌上浮。松手后信息框保留，点别处才关 |
| **继续按住到 1.2 秒** | 右键 | 打开原卡大图；牌组编辑器里打开卡牌窗口（数量、升级、备注、定制、移入副牌）；数量选择器和创伤里 −1 |
| 一根手指按住时，另一根手指轻点 | 右键 | 同上，不用等 1.2 秒 |
| 拖动 | 左键拖动 | 拖手牌出牌、拖到检定框投入；平移地图；滚动列表；拖动面板标题移开面板；牌组编辑器拖牌进出 |
| 双指捏合 / 张开 | 滚轮 | 以两指中点缩放地图 |
| 安卓返回键 | Esc | 关闭最上层窗口 → 离开全屏地图 → 打开游戏菜单（不会直接退出游戏） |
| 牌桌右侧 "⋯" 按钮 | 键盘快捷键 | 提示可点（F）、撤回一步（U）、展开队友（T）、调查记录（Tab）、全屏地图（M）、整张地图（Home） |

辅助显示：

- **按住进度环**：按住 0.4 秒后，手指周围出现一圈细环，转满（1.2 秒）就触发右键。只想看信息框时，在转满之前松手即可。
- **提示文字框**：桌面版里鼠标停留出现的小提示（牌堆张数、剩余生命/理智、修正后的费用和技能值、图标按钮的名字、牌组不合规的原因等），手机上不会自己弹出。现在按住时，如果手指下的东西有提示文字，就在手指上方显示一个大字号文字框，下次触摸时消失。
- 悬停延迟：桌面版的信息框要等"设置"里的悬停延迟（默认 1 秒）。手机上改为 0.1 秒，因为按住本身已经等了 0.4 秒。

## 3. 设计取舍

- **按住先看信息、再看原卡**：这和桌面版的习惯一致，悬停看数值、点击或右键看原卡（见"地图是牌桌中心"那条约定）。最重要的实时数值靠按住就能看到，不用打开大图。
- **轻点不悬停**：要是手指一碰就算悬停，每次点击都会弹信息框，所以只有按住才算悬停。
- **拖动要先移动 14 像素才算拖**：避免手指轻微抖动把轻点变成拖动。
- **双指操作会取消第一根手指的点击**：捏合缩放时不会误点到牌。
- "⋯" 按钮只在牌桌上、而且没有弹窗时出现，放在右边缘中间。位置还要在真机上确认会不会挡到东西。

## 4. 盘点结果（桌面版里只有鼠标/键盘才能做的事）

1. 右键：打开原卡（牌桌所有卡、徽章、地点、地图区域）；牌组编辑器的卡牌窗口（**只能右键打开**）；数量选择器和创伤的 −1（**只能右键**）；选人界面返回；关闭全屏地图。
2. 悬停：卡牌信息框和实时数值、地点信息框、幕/密谋牌、左上角剧本名（混沌标记效果）、选项指向的箭头、能力原文、牌组编辑器和工坊的大图预览、通关桂冠说明。
3. 提示文字：牌堆张数、胜利点、生命/理智、修正后的费用/技能/隐蔽值、额外行动、混沌袋、检定难度与技能值、图标按钮名字。
4. 滚轮：地图缩放（没有屏幕上的缩放按钮）；列表平滑滚动。
5. 双击：地图放大/全图；牌组库打开牌组。（手机上不再提供双击；地图用双指缩放，牌组用单击选中再点"编辑"打开）
6. 键盘：Esc、M、Home、Tab、U / Ctrl+Z、D、F、T、F12（截图，开发用）。

这些都已经被第 2 节的手势覆盖。D（抽遭遇卡）没放进 "⋯" 菜单，因为遭遇牌堆本身可以直接点；F12 只是开发用。

## 5. 还没解决 / 要在真机上看的

- **字太小**：界面按 1920×1080 设计，在 6 寸多的手机上会很小。"设置"里有文字缩放可以先用；以后可能要给手机单独调布局。
- "⋯" 按钮的位置；按住进度环和提示框的大小。
- 文字输入（房间码、牌组改名）用系统输入法，应该能自动弹出，还要确认。
- 盘点中发现的一个小问题（与手机无关）：地图按钮和全屏地图返回按钮的提示文字写着"(Tab)"，但 Tab 现在是开关调查记录，地图是 M。

## 6. 11-23 追加

- **按下反馈**：手指一按到按钮上，就给按钮发"按下"信号，主程序的点按效果（首页那种金色光条）立刻出现；抬起、开始拖动或第二根手指按下时恢复。真正的点击仍然在抬起时发出。
- **下拉菜单**（Yunke："所有的下拉菜单都不能正常使用"），原因有两层：
  1. 弹出菜单是嵌在主窗口里的子窗口。它打开以后，Godot 把触摸直接交给它，触屏层收不到；而它自己只认鼠标。
  2. 轻点下拉框时，紧跟在"按下"后面的"松开"被菜单当成选中了当前项，菜单马上关掉。Godot 只在真实鼠标键还按着时才忽略这一下，手指合成的点击不满足这个条件。
- **修法**：
  - 每个子窗口收到的触摸，翻译成鼠标事件，交回主窗口再转给它：点里面等于鼠标点击，拖动等于滚动；点外面关闭弹出菜单。
  - 轻点时，如果"按下"打开了一个弹出菜单，就不再发这一下"松开"。
- **验证**：Windows 上加 `--touch-test`，用 QA 动作 `touch-option`、`touch-item`、`touch-outside` 注入真实触摸事件，走 Godot 的完整输入流程。设置里的"界面缩放"下拉：能打开，选第 4 项和第 1 项都选中了，点外面能关闭。**已验证（Windows 模拟触摸）**；真机未验证。

## 7. 手机排版分支（11-23，"两处都改"）

只在手机排版分支（`com.yunke.arkhamui.layout`，`overlay-mobile` + `LAYOUT=mobile`）里生效；正式版 APK 行为不变。

- **小卡上的吸附**：之前点小卡本身，会被吸到卡角的"常 / 己 / 停 / 多"触发方式方块上，弹出触发方式窗口。现在手指落在一张卡上时，只吸这张卡自己的能力按钮（闪电、→，圆形、无文字）；没吸到就按卡本身处理，和原版一样（点卡直接用它的能力）。手指落在空桌面时照旧，7 毫米内最近的小按钮生效。手指在"⋯"或它的菜单上时不吸附。
- **安全边距**：手机圆角会切到四角的代币和按钮，横屏时摄像头开孔正好压在右侧"⋯"上。现在整张画面等比例缩进安全区：系统报告的开孔区域之外，再离每条边 2.5 毫米，四周补黑边。布局本身不变（约缩小 7%，130% 实际约 121%）。"⋯"按安全区摆放，输入按同样的变换换算。电脑上截图可以用 `--mobile-layout --safe-sim=left|right` 模拟左侧或右侧开孔。
- **验证**：Windows 模拟触摸（2000×900、130%、右侧开孔模拟），以下几项**已验证**：
  - 点闪电按钮旁约 3 毫米的空桌面，能力能触发；
  - 点卡身和原版同样反应；
  - "⋯"能点开；
  - 九个界面都完整，四角按钮在圆角外。
- **未验证**：真机上开孔和圆角的实际位置；该分支里的下拉菜单（这次找到的界面里没有可测的下拉框）。

## 8. 手指滑动滚动（11-23，两个版本都有）

- **问题**：拖动被转成鼠标左键拖动，列表里的卡片和按钮会把拖动吃掉，所以只能拖右边那条细滚动条（Yunke："无法用屏幕中间上下滑动"）。
- **修法**：在 TouchInput 里统一处理，没有逐个界面改。
  - 手指移动超过 14 像素时，找按下点下面最里层、沿拖动方向还能滚的区域（ScrollContainer、可滚动的 RichTextLabel、ItemList、TextEdit）。找到就由触屏层直接滚它，内容跟着手指走，快速一划松手后会带惯性滑一段。
  - 游戏收不到这一次的按下和松开，所以不会误点到卡片。
  - 有平滑滚动的列表用 SmoothScroll.Jump，不和它的缓动打架。
  - 以下情况仍然是左键拖动：横着拖（比如把卡池里的牌拖进右侧牌组）、拖滚动条本身、长按后再拖、不在可滚动区域里拖（手牌、地图、面板）。
- **QA 动作**（加 `--touch-test`）：
  - `touch-swipe:x1,y1,x2,y2[,毫秒]`：模拟一次手指滑动。
  - `touch-swipe-all:<标签>`：把当前最上层每个可滚动区域都滑一次，记录有没有滚动、界面有没有变。
  - `touch-scrolls`：列出所有列表的当前位置。
- **已验证**：Windows 模拟触摸，手机排版 130% + 右侧开孔模拟。每处都能滚，界面不变、没有误点：
  - 选择战役；
  - 继续调查；
  - 设置；
  - 牌组库左侧列表；
  - 新建卡组；
  - 组卡卡池、右侧牌组列表、筛选面板；
  - 牌堆查看；
  - 调查记录；
  - 剧情长文本。

  选择战役另外测了反向滑动和慢速滑动。组卡界面竖着滑只滚不加牌，横着拖仍能把牌拖进牌组（33→34）。
- **测到了但没能验证**：
  - 签名卡窗口：列表本来就在底部，没有测出滚动；
  - 弃牌堆、牌组库右侧预览：内容不够长，不需要滚；
  - 卡牌阅读、音乐面板：没有滚动区域（阅读器整段显示；音乐的下拉列表走第 6 节的弹窗处理）。

## 9. 牌桌常驻按钮：撤回、地图、全图（11-23，手机排版分支）

- **起因**：Yunke 说手机没有键盘，撤回和地图的快捷键需要有按钮。原来牌桌顶部图标栏只有"地图全屏"（46 像素，约 4 毫米），撤回只能从"⋯"菜单或记录里的 ↶ 进入，"整张地图"只在"⋯"菜单里。
- **改动**：TouchInput 加了 `TableButtons` 开关，只由手机排版分支的 MobileLayout 打开，所以正式版不受影响。
  - 开关打开时，牌桌上顶部图标栏正下方、队友栏左边，常驻一排按钮"撤回 / 地图 / 全图 / ⋯"，每个 88×88。
  - 三个按钮分别等于按 U、M、Home。"⋯"的菜单从按钮下方展开。
  - 最初放在右边缘竖排，两人局时会盖住右侧的队友栏，所以改成这一排。
- **验证**（Windows，2400×1080，130%，两人局和单人局，**已验证**）：
  - 结束回合后点"撤回"，退回调查阶段，资源和毁灭复原；

## 11. "缩放"与安全边距共用画布变换（11-23，2026.11.23.6）

- **问题**：主仓库新增的"缩放"（App.ApplyZoom）和手机排版的安全边距（MobileLayout.SafeArea）都写根视口的 CanvasTransform。安全边距每 0.15 秒覆盖一次，手机上的缩放就会失效。
- **处理**：MobileLayout 改为每帧写入合成后的变换：先按缩放绕画面中心缩放，再按安全区适配，即 `lastSafe * zoom`。ProcessPriority 设为 1000，保证在 App 之后执行。App 只在缩放值变化时写自己的那份，下一帧就被合成值接管。
- **验证**（Windows，2400×1080，130%，缩放 70%，模拟右侧开孔，**已验证**）：
  - 画面缩到中间，四周是黑边；
  - 新加的 QA 动作 `touch-win:x,y` 按截图像素发真实触摸：点截图里"设置"所在的像素，能打开设置；
  - `touch-button:设置` / `继续调查` 也能正常进入。
