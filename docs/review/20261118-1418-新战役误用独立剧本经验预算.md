2026-11-18 Yunke 确认开局可使用经验牌组，规则与 HTML 版一致。原阻塞已撤销。

## 发现

后台实测用罗兰的合法基础牌组换入 1 张 4 XP 的霰弹枪，给独立剧本预算设 4 后，从《狂热之夜》开局提交并推进到书房调查。核心存档中的罗兰抽牌堆有 1 张霰弹枪，已获经验 0、已花经验 0。经验卡入场符合 Yunke 确认的规则。该次样本包含独立剧本预算字段，省略此字段的开局留作回归用例。

- [准备页提交](../../app/Scripts/Screens/PrepareScreen.cs#L215) 与 [牌桌自动带入](../../app/Scripts/Table/TableScreen.cs#L124)。

- [本轮报告的后台回执](20261118-1418-基础游戏三章规则联接后台审查.md)，书房调查阶段 `seq=12`、`shotgunInDrawDeck=1`、`earned=0`、`spent=0`。

## 建议

按 Yunke 决定，战役开局使用现有 build 系统校验构筑合法性，开局 XP 校验免除。回归应覆盖合法的 0 XP 和含经验卡牌组，以及去掉独立剧本预算字段后合法经验牌组正常入场。
