# 可变伤害被显示成固定伤害

## 发现

攻击检定框固定从 1 点基础伤害起算，只加数值型 `DamageDealt` 和硬编码的致命打击，文案直接写“成功时造成 N 点伤害”。基础卡 `01029` 霰弹枪会用成功差值替换标准伤害，最少 1、最多 5。失败后打到另一调查员也可能按失败差值算。当前计算没有该类替换／差值分支，也没依据抽取后的实际伤害事件更新这个数。

这项是规则文本与现行显示路径的静态差异。新战役探针已确认该卡可进入当前客户端的牌局。霰弹枪实际开火、伤害回执与显示的逐帧比对尚未运行。

## 证据路径

- [伤害预测公式与固定文案](../../app/Scripts/Table/TableScreen.Panels.cs#L182)。
- [基础卡目录](../../app/assets/data/core-cards.json) `01029` 的攻击规则，以及 `01020` 大砍刀的交战条件。

## 建议

按核心提供的攻击来源、条件和实际生效的修正显示伤害。以霰弹枪成功差值 0／3／6、误伤另一调查员，以及大砍刀只与一名敌人交战／与多名敌人交战作对照。需要增补核心投影时，**需 Yunke 决定**。
