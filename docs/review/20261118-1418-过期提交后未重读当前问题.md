# 过期提交后未重读当前问题

## 发现

本轮后台在书房成功提交一次取资源后，用上一序号重投。核心明确拒绝 `StaleLocalState`，重新打开后可以继续。实际前端的 `Busy` 只提示异常，`Advance` 的多条自动路径随后用原状态继续。已有基础游戏自动游玩日志 `r10`／`r11` 分别记录 180／543 次相同异常，包含连串重复报错。

席位切换也可以保留同一个序号。本轮书房检定在序号 11 同时看到罗兰开始检定的选项和黛西可投入的选项。结算时改用另一席提交，核心拒绝，正确席位仍可提交。前端的自动结算计时器只比较序号，实际发出请求时取当前 `state` 的席位，存在旧选择和当前席位不匹配的路径。计时器竞态目前是源码结论，尚无人工输入复现。
