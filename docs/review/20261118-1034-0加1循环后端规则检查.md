## 发现

- **逐章覆盖 11/11，战役中有实际游玩回执 10/11。** 新跑的隔离探针确认两套战役都能创建并收到 `ContinueCampaign`，11 个独立剧本都能创建并收到 `PickScenarioSettings`。其中 0 循环 3 章返回受支持设置。敦威治 8 章均返回 `supported: false`，无法经独立模式走过设置关。战役从《毁灭之地》或《迷失时空》中途开始也实测返回高级设置未实现。既有战役回执覆盖 0 循环全三章与敦威治前七章，后者在第七章失败结束。第八章、幕间 II 正向分支和尾声仍缺战役实测。
- **规则核心与前端估算出现可解释的差异。** 《百赌百胜》的“歪打正着”会替换抽到的标记。回执同时保留原标记，审计公式按原面判为失败，实际核心在替换后判成功。吉姆的骷髅也出现基础数值和实际应用修正不同。现有证据把这两类问题落在前端展示或审计计算上。
- **撤回探针报错，实存游戏快照仅随机种子改变。** 新试的资源操作到达了正确的撤回目标。旧探针要求游戏 JSON 字节完全相等，忽略了现行撤回要求刷新随机种子。另一个自动通玩回执在回退重试后出现 60 次 `StaleLocalState`，应单独调查客户端如何处理过期提交。
- **规则版本待拍板。** 实测规则 DLL 与 `runtime/core.json` 自报一致，但与旧清单不符。沿用已有阻塞意见，由 Yunke 决定规则基线。

## 建议

1. **敦威治末段覆盖，重要。** 先取得通过第七章的干净战役回执，沿正常流程检查第八章和尾声。用另一条血色祭坛达成结局的路径核对幕间 II。对每个分支保留核心问题、选项、结果及发生改变的战役记录。要开放中途开章或补规则调用字段，**需 Yunke 决定**。
2. **检定面板与规则审计，重要。** 记录原始标记、实际被替换成的面、个体修正和核心结果。测试至少包含“歪打正着”前后的自动失败、吉姆的骷髅和《地底噬魔》的远古邪物。UI 最终结果应与核心的成败及差值一致。见 [吉姆检定意见](20261118-1003-吉姆骷髅检定显示与核心结算不符.md) 及 [黛西原始回执](../../evidence/pd6/samples/test-02062-AutoFail-MISMATCH.json)。
3. **撤回与过期提交，重要。** 撤回检查应分别核对行动资源、手牌、线索和当前问题等局面状态，以及随机种子刷新规则。复跑半途与重开后撤回。对 `pd6` 集中出现的 `StaleLocalState`，检查是否复用撤回前的序号或选项，记录刷新后是否能继续。已有失败属于自动通玩路径，正常鼠标路径待核实。
4. **规则基线，阻塞。** **需 Yunke 决定**是否使用 `classic-fast-1.0.5` 作为验收基线和旧清单的处理方式。沿用已有 [基线阻塞意见](20261118-0959-规则核心替换来源.md)。
