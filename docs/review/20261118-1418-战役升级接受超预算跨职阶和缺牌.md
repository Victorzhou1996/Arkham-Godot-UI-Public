# 战役升级接受超预算跨职阶和缺牌

## 发现

从第一幕间真实生成的黛西升级问题分出三个全新的隔离游戏。黛西可用 2 XP。通过与前端相同的 `PrototypeBackend.UpgradeDeck` 提交后，三副异常牌组都进入《午夜假面》：

- 以两张超感知换两张 2 XP 的百科全书。下一章牌组有两张百科全书，核心显示共花 2 点。
- 以一张超感知换入 0 级流浪者卡里奥·德·卢卡。下一章有该牌，核心显示共花 2 点。
- 移除一张超感知，未补卡。牌组总张数从 33 到 32，下一章仍为 32，核心显示共花 2 点。

主界面的完成按钮有普通张数和本地费用检查。工坊关闭“仅可用卡”后，加入牌不会再次检查职阶。升级模式的“校验牌组”仍走独立剧本校验，保存动作也没有将该校验作为提交前置条件。

2026-11-18 Yunke 确认牌组校验与战役升级均以现有 build 系统为基底。让“校验牌组”和“完成升级”共用构筑检查。开局只检查合法性，升级提交另按本次变更检查应扣经验和该席位余额。用真实幕间状态重测超预算、跨职阶、少一张和同名不同等级超限，核对拒绝后的牌组、经验及待答问题。涉及 DLL 改动时 **需 Yunke 决定**。拒绝时的草稿处理已在 [此前意见](20261118-1003-战役升级被拒时丢失编辑草稿.md) 记录。
