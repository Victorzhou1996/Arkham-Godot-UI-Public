# 未揭示地点能提前读取揭示面

## 发现

《聚集于此》整图的地点浮窗根据核心的 `revealed` 显示“未揭示”，随后仍调用通用的 `Peek.CardBox`。后者直接读取卡目录的 `text`（揭示面）。整图地点的右键阅读同样只传卡号，阅读器默认显示正面，并提供翻面入口。

卡目录中的阁楼 `01113`、地窖 `01114` 的揭示面分别写明进入时受到恐惧与伤害。客厅 `01115` 的未揭示面写着屏障挡路，揭示面写的是撤退和与丽塔谈判。当前代码把两面的游戏信息暴露时机混在一起。

## 建议

地点浮窗和阅读入口都用同一次核心视图指定当前可读的卡面。用首幕推进后玩家站在走廊的隔离局面核对三处地点，进入前只能读取未揭示面，翻开后才显示对应的强制效果或地点能力。若要变更玩家能看到的卡面范围，**需 Yunke 决定**。
